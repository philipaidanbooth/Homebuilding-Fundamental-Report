# U.S. Homebuilding Fundamentals

A one-week case study on the fundamentals of U.S. homebuilding: what's driving the industry right now and what to watch going forward.

## Where to start
- **`report/`** – the full report
- **`executive_summary/`** – the one-page version

## What's inside
| Folder | What it covers |
|---|---|
| `00_primer` | Homebuilding industry primer |
| `01_affordability` | Mortgate rates |
| `02_inventory` | New vs. existing home supply |
| `03_costs` | Land, labor and materials |
| `04_margins` | How builder profitability is holding up |
| `05_scenarios_signposts` | upside/base/downside cases and the indicators to watch |
| `06_appendix_sources` | Data and sources |
| `07_methodology` | Methodology section |
| `data_ready` | Cleaned datasets |

## Tools
Built in R. Data comes from FRED, the U.S. Census Bureau and other public sources (full list in `06_appendix_sources`).
